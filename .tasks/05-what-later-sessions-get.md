# 05. What later sessions get

## What to build

The listing and the digests. The `# Attached files` listing every session's
prompt ends with groups an Answer's files under the Set and the Question they
answered — one group per Answer, headed by the Set's title and the label, in
the order the files were attached, after the Brief's group — in the same
neutral tone: the path and the size, and nothing about what to do with it.

The digest folded into the next session for a Deferred Ask, and the summary a
relaunched grilling is primed with, name an Answer's files under its decision
by the path the session reads them at, so a session brought up to speed on an
exchange it did not see knows what was handed over with each Answer.

CONTEXT.md's Attachment entry says how an Answer's files reach a session, and
its Deferred Ask entry says the digest names them.

## Acceptance criteria

- [ ] A session's prompt lists an Answer's files under the Set's title and
      the Question, after the Brief's, and a Conversation with only Brief
      files lists as it does today.
- [ ] The digest of a deferred Set and the relaunched grilling's summary each
      name the files under the Answer they were put on.
- [ ] CONTEXT.md's Attachment and Deferred Ask entries say so.
