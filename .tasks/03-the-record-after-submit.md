# 03. The record after Submit

## What to build

The answered Set as everybody reads it. Where the Set page draws the record
of an Answer — under the decision, on the Set page reached from the Timeline
and in a Share alike, which draw the one sheet read-only — an Answer that has
files draws them as the same read-only pills the frozen Brief pane draws:
name and size, no ×. A Set the agent locked unanswered keeps its files and
draws them the same way under the Question they were put on. A Share carries
the names and sizes and never the bytes, which the rows on the Set view
already give it.

Once a Set has settled, the sheet offers no paperclip and no ×, and the
endpoints refuse both as task 01 has them. The Timeline row for a Set changes
nothing: what it summarises is the Set, and the files are read on the page.

## Acceptance criteria

- [ ] An answered Set's page draws each Answer's files as read-only pills
      with sizes under that Answer, and one locked unanswered draws its files
      the same way.
- [ ] A Share of the Conversation draws the same pills and carries no bytes.
- [ ] After Submit the sheet draws no paperclip and no ×, and the web and
      server suites cover both.
