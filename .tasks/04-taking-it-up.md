# 04. Taking it up

## What to build

The press on a Draft holding a pull request, and the tail of Start work on the
compose page: the Conversation is put on the pull request's branch and moved
into Wrapping.

In order, on the blocking side: the two roles are read and checked as a grill
start checks them; origin is fetched; the head branch is settled by the rules
the grilling fixed — made off origin's where no local branch exists,
fast-forwarded where a local one is behind origin, **refused by name** where
it is ahead or has diverged, and **refused naming the place** where it is
checked out in the human's own checkout or another worktree; the worktree is
checked out on it, and every companion's beside it as an adoption does; the
base commit recorded is the pull request's head at take-up and the base branch
recorded is the one GitHub names, so the commit sweep draws nothing that was
already on the pull request and a conflict merge of the base drags nothing;
the branch is named — the Conversation's name is the pull request's branch,
settled, never invented; and the pull request is recorded as the move from
Draft into Wrapping, which today is refused from Draft and must be allowed for
a Conversation holding one. The wrap-up watchers start as the finish step
starts them.

A refusal is one outcome named for what refused it and is said on the
composer where the press was, as an adoption's refusals are. Nothing made
before a refusal outlives it: a branch fast-forwarded stays fast-forwarded, a
worktree made is unmade.

The Timeline of a taken-up Conversation reads the Brief, then the pull request
card, and no commit cards. The pull request's draft flag on GitHub is not
touched.

## Acceptance criteria

- [ ] With no local branch, the press ends Wrapping on a worktree of the head
      branch tracking origin, the pull request pinned, the two Pairings
      recorded and the watchers running.
- [ ] A local branch behind origin is fast-forwarded and taken; one ahead of
      origin, and one checked out in another worktree, each refuse by name on
      the composer and leave the Conversation a Draft.
- [ ] The Timeline holds the Brief and the pull request card and no commit
      cards, and a commit the base branch gains afterwards draws none either.
